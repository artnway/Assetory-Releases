# Assetory для 3ds Max

Assetory помогает собрать библиотеку моделей, материалов и текстур и пользоваться ею прямо в 3ds Max. Добавьте папку моделей с готовыми категориями, найдите нужный ассет по тегам и перетащите его в сцену.

## Что внутри

| Инструмент | Что можно сделать |
| --- | --- |
| **Браузер ассетов** | Собирать свои библиотеки, организовывать ассеты по папкам и тегам, импортировать архивы и добавлять модели в сцену. |
| **PBR Builder** | Собрать материал для Corona или V-Ray из набора карт, проверить их назначения и задать реальные размеры текстур. |
| **Copitory** | Переносить модели, материалы и карты между сценами. Модели сохраняют исходные координаты. |
| **Merge** | Вставить в сцену несколько файлов или моделей из архивов за один проход. |
| **Relink** | Найти потерянные текстуры и восстановить пути к ним в сцене или библиотеке. |

## Установка и обновление

1. Откройте [последний релиз](https://github.com/artnway/Assetory-Releases/releases/latest) и скачайте файл `.mzp` из раздела **Assets**.
2. В 3ds Max выберите **Scripting → Run Script** и откройте скачанный файл.
3. В **Customize User Interface → Artnway Scripts** найдите команду **Assetory**. Её можно добавить на панель или назначить ей горячую клавишу.

При открытии Assetory проверяет наличие новой версии в фоне. Ручная проверка находится в **Настройки → О программе → Проверить обновления**. Для обновления закройте Assetory и запустите новый MZP. Библиотеки и настройки сохраняются.

Установка проверена в **3ds Max 2024 и 2027**. Интерфейс доступен на русском и английском.
